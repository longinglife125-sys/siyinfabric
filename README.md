# siyinfabric
SIYIN provides custom neoprene fabric and stretch fabric solutions, including laminated neoprene, nylon spandex and yoga fabrics for sportswear, outdoor and functional products. OEM &amp; ODM available.
# SIYIN Fabric static website

Open `index.html` in a browser to preview the site.

Pages:
- `index.html` home page
- `yoga-fabric.html` yoga fabric category page
- `neoprene-fabric.html` neoprene fabric category page
- `product.html?id=tie-dye-fabric` product detail template

Edit `products.js` to add product photos or new products.
